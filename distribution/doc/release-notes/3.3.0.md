# Version 3.3.0

Visible signatures now render Chinese, Japanese and Tamil text.

- **Visible signature text in Chinese, Japanese and Tamil** — the bundled DejaVuSans has no glyphs for these scripts, so the DSS engine failed and the OpenPDF engine silently left the characters out of the translated default text or a signer name. JSignPdf now falls back to the bundled Noto Sans SC or Noto Sans Tamil font, and refuses to sign when no font covers the text (for example Korean) instead of dropping characters. The DSS engine embeds only the used glyphs, so a visible signature no longer carries the whole font. See issue 537.
- **Larger downloads** — the bundled Noto Sans SC font adds about 6 MB to every ZIP and installer.
